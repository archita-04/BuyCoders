# BuyCoders
BuyCoders is an AI-powered smart shopping assistant that helps users compare products across platforms, understand real customer feedback, detect fake discounts, and get clear, explainable recommendations based on their needs and budget.
## ❗ Problem

Online shoppers face:

- Time-consuming product comparisons
- Misleading discounts
- Thousands of unstructured reviews
- Lack of transparent recommendations

---

## 💡 Solution

BuyCoders provides:

- Cross-platform product comparison
- AI-based review filtering
- Pros & Cons extraction
- Fake discount detection
- Explainable product recommendations

---

## 👥 Target Users

- Students  
- Working professionals  
- Budget-conscious buyers  

---

## 🧠 Key Features

- Chat-based smart search
- Review sentiment analysis
- Transparent ranking system
- Personalized recommendations

---

## ⚙️ Tech Stack

- Python

- Pandas
- spaCy
- VADER Sentiment Analysis
- AWS (EC2, S3 – deployment ready)
